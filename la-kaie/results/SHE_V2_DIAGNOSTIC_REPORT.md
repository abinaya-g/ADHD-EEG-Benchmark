## 3. B-2: zero-variance artefact windows

**What a window is.** A "window" is one artefact computation: the current buffer of successful native displacements of one population, evaluated once per iteration once ≥ 2D rows exist. Successive windows **overlap**. Counts are the windows with ≥ 1 coordinate of exactly zero standard deviation.

| S3 D20 | 0 / 2610 (0) | 0 / 2610 (0) | 0 / 2610 (0) | 0 / 2610 (0) |

H = HBA population, M = MPA population.

**Zero-variance windows are far more common than Stage 1's warning count suggested.** On S1, about **57%** of HBA-population windows contain a zero-variance coordinate.
- They occur on S1/S2, which runs solve to f ≈ 0 (S1 median final best ≤ 10⁻²⁷), and never on the rotated S3, which is not solved.
- They are almost exclusive to the HBA population.
- This fits the convergence explanation suggested in `SHE_STAGE1_FOLLOWUP.md` (b): coordinates sitting exactly at their optimum. That explanation is still an inference; which coordinates were constant was not logged.
- The Stage 1 count of "19 warning occurrences" was a lower bound, de-duplicated once per worker lifetime, as that follow-up stated. It was not a window count.

- The noise floor uses the same formula as the primary r, with the mean window size of the retained windows.

**Reading.**
- **Nesting did not change the outcome.** Every structural model now contains h0's features, so it can at worst match h0 up to estimation cost. Yet h0 keeps the largest mean π̄ in **all 12 cells** (6 cells × 2 variants). The only movement is a softening of h0 dominance on S2 D20 (max π̄ 0.60 → 0.31), and there the posterior moves towards *uniform*, not towards the true hypothesis (h2).
- On S1, h0 dominance became **stronger** under nesting (max π̄ 0.31 → 0.52).
- This is exactly the outcome stated in advance in B-4: **structural terms add no prequential predictive value beyond step size**. Their extra 2D (+pairs) parameters cost more online-estimation loss than they recover.
- The cause of the Stage 1 failure therefore **cannot** be attributed to the non-nested specification.

- **Scope.** Synthetic S1–S3 only, D ∈ {10, 20}, a single budget, pre-tuning defaults; only η/ρ were swept. Not run on CEC2022/FIR.
- **Nested model, no h0.** A nested run *without* h0 in the hypothesis set (SHE-no-h0) was not run.
- **Model form and outcome definition.** Whether a lower-dimensional structural model or a different outcome definition (other than y = 1[f(x') < f(x_r)]) would show a signal was not tested. That would be a redesign, which B-0 excludes.
- **Causes of zero variance.** Which coordinates were constant, and at what stage of the run, was not logged. The convergence explanation is an inference.
- **Zero-variance windows elsewhere.** The B-2 recomputation of r covers the primary variant on S1 only (the H-E4(b) cells). For the Uniform variant and for S2, only counts are reported.
- **Time-limit interruption.** I checked that no partial or temporary files remained and that all 360 records are valid with the same commit. I did not independently re-run any of the 160 pre-interruption runs. Determinism given the seed is tested (T-SHADOW-style passivity and the bit-identical Stage 1 test), not proven for every run.
